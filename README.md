# Power System Fault Analysis Simulator

Project workspace for MATLAB and Simulink-based power-system fault analysis.

## Structure

- `docs/` — project assumptions and validation planning
- `matlab/` — MATLAB configuration, network, fault, protection, analysis, and reporting code
- `simulink/models/` — Simulink models
- `tests/` — unit and integration tests
- `results/` — generated plots and reports
